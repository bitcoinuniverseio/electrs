# Alternative confinement proof source, unexecuted

The source bootstrap is a concrete prototype; it has not been compiled, run or wired into the workflow. Current workflow remains the owned read-only metadata successor04c. No retry of the failed namespace unit is authorized by this document.

`confinement-proof.c` uses only existing Linux headers and libc. The reviewed next driver must compile this exact trusted source with the observed absolute GCC13 tool/hash, `-static`, in a unique resource-capped user unit; existing static libc/header availability must be checked first. No package install, dynamic-link fallback, arbitrary compiler wrapper, dependency acquisition or native Cargo build is allowed. The compile environment must be clean and output limited to a new private RUNNER_TEMP directory. Compilation/resource enforcement and driver orchestration remain separate review gates.

The generated static ELF closes all3+ descriptors with close_range after replacing stdin/stdout/stderr with owned nonnetwork handles. It deliberately opens a controlled descriptor100 first and proves EBADF afterwards. No old socket/ring descriptors remain; fresh exec removes old mappings. Missing close_range fails closed.

Before creating the task root or unit, the small proof requires at least1GiB MemAvailable and1GiB temporary disk, CPU pressure at most25% and IO pressure at most5% across all reported10/60/300-second averages. This is a small-proof admission snapshot, not durable full-build headroom. Its64MiB/15s unit caps are unchanged. Success carries the exact compiled receipt/source/binary/static-ELF evidence and observed readelf pin, labels compiledTinyControl true and fullRustBuild false. Failures expose at most32KiB of own known compile/proof/unit stderr/stdout; exact captured bytes remain base64-addressable and original files/primary errors are preserved.

It requires Landlock ABI3 and explicit read/write/execute/create/remove/refer/truncate rights. Only the private proof directory is allowed; no whole-home, tool or credential subtree is granted. The proof needs no dynamic libraries because static linking is mandatory. A later compiler wrapper must add separately reviewed exact read/execute tool, stdlib, include and vendor leaves, plus exact ld.so.cache access where needed, without broad home/proc grants. Missing ABI/rights fail; no best-effort protection downgrade.

The seccomp filter checks x86_64 and rejects x32/other architectures. It denies networking families including Unix socket/connect/sendmsg, all three io_uring syscalls, descriptor/process theft, bpf, namespace/mount changes and ioctl/signal operations not needed by this proof. The static child validates exact EPERM for networking and io_uring, outside write/truncate denial and positive private file operations, then proves restrictions survive fork/exec. Invalid-fd probes cannot contact Core. No notification broker or privilege escalation is used.

A later root-reviewed driver still needs actual CPU/memory/pids/Nice/IOWeight readback and unit properties without ignored namespace claims, owned release/actual exit, original error retention and exact-unit cleanup. Kernel enforcement is unobserved. The restrictive signal/ioctl policy is for this small proof; full Cargo/C++ compatibility, read-root policy, total resources and complete Linux/RocksDB/Hyper qualification remain open. Landlock/filters alone are not a complete sandbox claim.

Primary references: [Landlock kernel API](https://docs.kernel.org/userspace-api/landlock.html), [seccomp kernel API](https://docs.kernel.org/userspace-api/seccomp_filter.html), and [kernel io_uring networking source](https://raw.githubusercontent.com/torvalds/linux/v6.8/io_uring/net.c). The last is an illustrative pinned source, not observed host kernel parity.
